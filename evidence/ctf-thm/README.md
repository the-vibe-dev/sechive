# CTF and Training Evidence Summaries

These summaries are derived from completed local training writeups. Raw writeups were not copied because they include lab IPs, flags, credentials, and challenge-specific answers.

## Included Summaries

- Dave's Blog: web authentication bypass, command execution validation, binary exploitation, privilege escalation.
- Boiler CTF: service enumeration, web foothold, local privilege escalation, controlled evidence capture.

## Publication Boundary

Flags, exact hosts, recovered credentials, and exploit strings are redacted. The summaries preserve capability evidence without turning the portal into an answer key.
